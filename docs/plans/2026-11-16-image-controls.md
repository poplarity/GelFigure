# 图像操作精简设计与实现计划

用户在 Marker 侧栏简化完成后，明确要求第一步图像 UI 和操作也做同类精简；沿用已确认的常用直达、进阶按需展开方式。

目标：导入自动处理后，只需核对胶种、方向、黑白显示和自动对比度。胶种始终可切换；旋转/翻转明确标注 90°，自动转正在一级。精确角度、滑块、网格和恢复自动角度放到“微调角度”；灰度原图不显示不可用的原色切换。自动对比度保留一级，手动黑白点、直方图、恢复导入对比度和过曝像素覆盖放到“手动调节”。Gamma 仍需显式解锁并标明非线性，识别依据按需展开。重要的相机过曝/色阶削顶摘要不能藏起来。

保留原有控件 id、科学处理算法、撤销、图像与标注坐标、项目/模板格式。使用说明和英文同步。关闭折叠区时移除临时参考网格，切换项目时恢复折叠区的初始状态。已保存的非默认 Gamma 应在摘要中提示，并能找到该设置。

步骤：
1. 添加 tests/image-controls.mjs；验证初始精简、展开可用、自动/手动调整与撤销、恢复导入值、彩色/灰度状态、过曝提示和项目切换，先观察失败。
2. 重排 index.html 图像区和 css；js/ui.js 同步摘要、只在可用时显示原色入口，明确 reset 按钮语义。
3. 针对新的异步自动转正动作核对状态身份，防止换项目后对新图执行旧请求；新增回归。
4. 三引擎专项与既有颜色/方向/版式检查、离线构建和桌面截图。整合最终 dev HTML，main 保持已发布版本。
