# Marker 操作简化设计

用户于 2026-11-16 确认采用侧栏方案：每个 Marker 保留泳道、型号、单位、核对条带；型号使用统一搜索窗口，样式与条带明细折叠，收藏、自定义、备份归入库管理，多 Marker 操作明确作用对象。

## 问题与目标

当前泳道、型号、匹配、标签操作在侧栏、参考卡、浮窗中重复；换型号有立即应用和先预览两种行为。保存自定义型号会隐式替换第一个 Marker。改版让正常识别后的核对简单，出错时有明确修正入口。

## 交互

- 侧栏每个 Marker 卡片：泳道下拉、带名称的型号选择按钮、单位下拉、核对条带按钮。显示已定位/总数和已显示条数；低吻合度写明需要核对。
- 一个型号窗口：标题注明目标泳道；按品牌、型号、货号、条带大小搜索；展示候选的完整名称、条带和参考带；选候选只预览，点击“应用并识别”才更新当前 Marker，并保留撤销。
- 校准卡只负责实际条带定位：显示当前泳道/型号、待定位大小与操作提示、“完成”出口。更换型号仍进入同一型号窗口。选择大小后点击实际条带，或点击已有黄线编辑。
- 样式和条带明细默认折叠；单位仍在一级。删除 Marker、重新识别、精简标签放在明细中。图上数字的快捷编辑保留，所用单位/字重控件与侧栏一致；通用字号说明影响全部 Marker。
- 库管理收纳常用、自定义、导入/备份。自定义默认只保存；从某个 Marker 的型号窗口进入时，明确显示“保存后使用在：泳道 N”。异步保存期间若切换项目或目标 Marker 消失，只保存到库。
- 型号窗口、库窗口支持 Escape、Tab 焦点循环、关闭后回到触发控件；切换项目或撤销导致目标失效时关闭编辑，防止修改错误泳道。

## 数据与边界

不改变检测算法、原图像素或默认泳道间距。保留项目、模板、自定义库、手动定位及隐藏/删除语义。更换型号重建该 Marker 的匹配；预览、收藏和普通库保存不改变图。手机端不扩展功能，但既有测试继续检查回归。

截图间距核验：原图泳道线与成图文字定位点等距；45° 起点对齐使短 M 与长名称的包围盒留白不同。已用相同四个名称在 Chromium/WebKit 复现；90° 竖排可得到均匀的水平文字占宽。本次不改既有文字角度或挪动原胶数据。

## 验收

自动化覆盖多 Marker 作用域、搜索/预览/应用/撤销、无结果、项目切换、库保存无隐式修改、目标保存、单位/样式/条带可见性与折叠状态、键盘。完整三引擎回归和离线单文件；检查桌面 Safari/WebKit 可读性、控件尺寸与高亮。
