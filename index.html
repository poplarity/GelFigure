在手机上

  • 底部切换原图 / 成图 / 设置，右下角是导出；顶部 ↺ ↻ 撤销 / 重做，⋯ 里有打开、保存项目和语言。
  • 原图：双指缩放、拖动。点泳道线或上方的泳道号选中，底部会出现微调、剪除、删除按钮；在红框内双击（或点“＋ 泳道”）加泳道；拖红框的边改出图范围，拖黄线修正 Marker 条带。
  • 成图：点灰色泳道号输入名称，键盘上的“下一项”跳到下一条；小字看不清点“放大”。分组横线：依次点首尾两个泳道名。
  • 导出：PNG 生成后长按图片即可存到相册或发给朋友；“分享 / 存储”可以把任何文件存到“文件”或发到其他 App。
  • 在微信里打开时无法下载文件：点右上角 ··· 选择“在浏览器打开”。

离线使用：只下载一个文件

下载 GelFigure-v0.6.4.html，保存到电脑，双击用浏览器打开即可。不用安装、不用解压。仓库里的 index.html 单独下载不包含完整工具。

关闭前点“文件 → 保存项目”（手机在“设置”中），将原图和标注存为 .gelfig 文件；下次打开项目即可继续。

最快的出图方式

  1. 拖入胶图 —— 转正、裁切、泳道、Marker、对比度全部自动完成。同一块胶的多张曝光可以一起拖进来，自动挑最好的一张。
  2. 在右侧成图上点泳道名输入，回车自动跳到下一条（也可在左侧一次粘贴一整行名称）。
  3. 核对左侧 Marker 型号是否正确。
  4. 右上角"导出 PNG"。导出前会自动检查常见问题。

常用操作

  • 只出一部分泳道：左侧"出图范围"选孔号，或在原图上拖红框左右边。泳道名称不会丢。
  • 剪掉中间某条泳道：在原图上选中后按 H（或取消"显示"），会自动加拼接间隙，图注中需说明。
  • 分组横线：在成图上从一个泳道名拖到另一个泳道名。
  • 目标条带箭头：点"目标条带"，再点那条带；大小按 Marker 估算，超出 Marker 范围会标 ≈。
  • + / − 条件行：加一行后，在成图上点格子即可在 + / − / 空 之间切换。
  • 泳道线没对齐：把最左、最右两条泳道线拖到对应泳道中心，填泳道数点"对齐"，中间泳道自动等间距。选中泳道按 Delete 或 ⌫ 删除。
  • 区域框：在原图上拖出矩形，可选在成图旁放大展示。侧边括号：在原图上拖过一段区域（拖尾、多聚体）。侧边文字：染色方法、抗体、曝光时间，放在胶图侧边或下方。目标条带也可标成 *（非特异条带）、# 或 †。
  • Marker 条带不对：在原图上上下拖那条黄线，其余条带会围绕它重新匹配。
  • 旋转：标注会跟着图一起转；可打开参考网格目测。

图像规范

  • 只做全图线性调整；Gamma 默认锁定为 1。
  • 区分相机过曝（只能重拍）和色阶削顶（可调回）。
  • 剪除泳道会自动加拼接分隔；不同凝胶不可拼进同一面板。
  • 建议同时导出"未裁切图"和"原始数据"放补充材料。

快捷键：Ctrl+Z 撤销 · Ctrl+Shift+Z 重做 · 空格+拖动 平移 · 滚轮 缩放 · H 剪除/恢复泳道 · Esc 取消当前操作
