# GelFigure Agent v1 contract

This implementation follows the user-approved local-first design. Public tool outputs are compact JSON; files stay on disk. Normal webpage sources, UI and offline build remain dependency-free and unchanged. The agent package depends on a pinned managed Chromium runtime, not system Chrome.

## Shared service

`agent/src/service.mjs` exports `AgentService` with constructor `{workspace: absoluteExistingDirectory, timeoutMs?:120000}` and async `doctor()`, `ladders({query?,kind?})`, `analyze({input,out,gelType?,orientation?})`, `prepare({analysis,spec,out})`, `render({plan,out})`, `revise({plan,spec,out})`, `validate({plan})`, `close()`.

All paths are relative to configured workspace or contained absolute paths; input/output symlink escapes rejected. New task output directory must not already exist. Reads include no remote URLs. Public service methods return `{apiVersion:'1',status, ...}` or throw AgentError `{code,message,details?}`. `status` is `succeeded`, `awaiting_answers`, `ready_to_render`, `needs_review`, `failed`. CLI exits 0 for success/ready,2 for awaiting/review,1 for failure. No `eval`/arbitrary scripts. MCP SDK stdio wraps same service, with stdout protocol-only. App processes one task at a time in serialized queue, isolated browser context per operation. A browser is reused per service.

Analyze creates `analysis.json`, `project.gelfig`, `diagnostic.png`. analysis includes `{apiVersion:'1',kind:'gelfigure-analysis',engineVersion,revision,source:{sha256,name,width,height,bits},project:'project.gelfig',lanes:[{id,number,x,name,hidden,marker:boolean}],markers:[{laneId,ladderId,fitScore,matched,total,bands:[{size,y,matched,manual,show}]}],gelType:{value,confidence,manual},rotation,crop,quality:[Issue]}`. Coordinates are explicitly `oriented-image-px`. Lane ID `lane_001` etc stored on project lane metadata `agentId` and revision guards bindings. Revision = sha256 canonical normalized project state + original SHA + project-carried custom ladder definitions, excludes savedAt/runtime timestamps. No scientific certainty derived from scores.

Prepare loads validated analysis + original project, accepts spec, validates semantically, applies only valid resolved changes to an isolated project, runs layout/quality checks without final export. Creates `plan.json`, `project.gelfig`, `resolved-spec.json`, `quality-report.json`; diagnostic optional. `plan` includes `{apiVersion:'1',kind:'gelfigure-plan',status,engineVersion,analysisRevision,revision,sourceSha256,project:'project.gelfig',spec,questions:[Question],quality:[Issue],digest}`. Digest = sha256 canonical whole plan except digest, no dates. Render revalidates digest, project hash/revision, engineVersion,questions and recomputes checks. Never accepts merely editing status to ready. Tampered/changed input rejected. Plan ready only when critical semantics resolved and blocking technical checks satisfied or a documented permissible warning is acknowledged. Render never executes unresolved plan. Revise = prepare a new plan from an existing plan/project, merged spec, no automatic final rendering. Any semantic change rechecks gate.

## Input spec v1

```json
{"schemaVersion":"1","expectedRevision":"analysis or previous plan revision","gelType":"dna","orientationConfirmed":true,"laneLabels":[{"laneId":"lane_001","text":"M"}],"markers":[{"laneId":"lane_001","ladderId":"gr1kbplus","unit":"bp"}],"markerPolicy":"specified","groups":[{"from":"lane_002","to":"lane_004","text":"Treatment"}],"conditions":[{"name":"Drug","values":{"lane_002":"+"}}],"annotations":[{"type":"sideText","text":"Agarose","position":"below"},{"type":"arrow","laneId":"lane_002","size":1000,"text":"Target"},{"type":"text","text":"Note","at":{"x":0.5,"y":0.5,"space":"crop-fraction"}}],"layout":{"figureWidthMm":85,"fontPt":7,"fontFamily":"Arial","labelAngle":"auto","laneNumbers":false},"image":{"display":"gray","invert":false,"gamma":1},"exports":{"dpi":600,"formats":["png","svg","tiff","pptx"]},"provenance":[{"field":"laneLabels","source":"record","reference":"ELN experiment123 / lane table","confirmed":true}],"conflicts":[{"id":"conflict_1","field":"laneLabels","message":"record differs","resolved":false}],"acknowledgements":["SOURCE_SATURATION"],"allowUnlabelledLanes":false}
```

Spec bounded strict validation: reject unknown fields, invalid enum/unit/font/missing or duplicate ids, no numeric strings, no NaN/nonfinite, invalid rotations and out-of-range positions. `gelType` dna/protein; must be explicitly declared; `orientationConfirmed` true required. All visible lanes need labels or allowUnlabelledLanes true (explicit omission). `markerPolicy` `specified` (explicit marker assignments with known valid ID/unit) or `omit` (remove marker roles, do not assign sizes). `expectedRevision` must match analysis or prior plan revision. `provenance` records user/record/detector/default; detector cannot mark sample names or model identities as externally confirmed. Existing records referenced, not executed. unresolved conflicts always question. Incomplete semantics return question not partial final.

Defaults: layout fontPt7 Arial labelAngle auto laneNumbers false, gel width existing unless figureWidthMm given; image gray/gamma1/unchanged invert (agent mode starts uninverted); export png/svg dpi600. Total figure width includes all margins. Ratio/pixel guards prevent extreme allocation. Any image adjustment is global; no local paint or band alteration. Hidden/cropped lanes remain preserved in project unless explicit corrected lane geometry implemented; API v1 modifies no topology by implicit name count.

Issue `{code,severity:'error'|'warning'|'info',message,field?,evidence?,acknowledgeable?:boolean}`. Question `{id,field,message,options?:[{value,label}],evidence?}`. Semantic unresolved issues non-acknowledgeable. Stable codes at least GEL_TYPE_REQUIRED,ORIENTATION_REQUIRED,LANE_LABELS_REQUIRED,MARKER_POLICY_REQUIRED,UNKNOWN_LANE,UNKNOWN_LADDER,UNIT_CONFLICT,UNRESOLVED_CONFLICT,INVALID_SPEC,STALE_REVISION,SOURCE_SATURATION,CONTRAST_CLIPPING,LOW_EFFECTIVE_DPI,MIN_FONT_SIZE,LABEL_OVERLAP,MARKER_UNMATCHED,EXTRAPOLATED_SIZE,FONT_ENVIRONMENT. Technical warning acknowledgements explicit and recorded, never invent data. `matched`/quality remain measurements not calibrated probabilities.

## Planner module worker boundary

`agent/src/plan.mjs`: exports `normalizeSpec(spec)`, `mergeSpec(base,patch)`, `semanticQuestions(analysis,spec,ladders)` returning array; pure synchronous. `agent/src/common.mjs`: exports `AgentError`, `canonical(value)`, `digest(value)`, `revision(projectData)`, `sealPlan(plan)`, `verifyPlan(plan)`, `assertRevision(expected,actual)`. Use Node builtins, no dependencies needed. `revision` derives source SHA, project state and project-carried custom ladders; matches browser serialization. `normalizeSpec` default fills only nonsemantic fields, not required gelType/marker policy/labels. All semantic missing fields are questions, syntactic bad values throw INVALID_SPEC. Normalized output only public spec, no extra injected origin fields. `mergeSpec` merges plain layout/image/exports objects; replaces supplied arrays/laneLabels/markers etc; omitted keeps old; no object-prototype keys. Unit strings exactly bp,kb,auto,bp-inline,kb-inline,kDa,kDa-inline,none consistent kind. Builtin ladders objects `{id,name,kind,sizes,ref}`.

## Skill and package

Skill references schema/prepare questions, host-native ask-user or normal conversation and wait, no render before ready, evidence citations/record scope, compact outputs/no pixel/base64 dumps. Doctor/list/analyze/prepare/render/revise/validate MCP names `gelfigure_<method>`; `doctor` optional. Return resource paths; optional bounded preview resource tools not arbitrary raw filesystem.

Portable bundle script assembles node executable, node modules, matching managed browser and app files; wrapper scripts start bundled node directly. Build host bundle actually run on macOS arm64 here; CI matrix builds/test portable bundles on supported Linux/Windows/macOS. No claim all platform installers signed until tested. No npm publishing or main release in this task. One portable zip/tar + skill zip for testing.
